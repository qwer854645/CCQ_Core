# CCQ Core 0.4.65

- Omni Speed Controller output convey now follows Create's Rotation Speed Controller: scrolled target RPM is applied directly to ordinary ±1 receivers.
- Removed the outbound dependency on non-zero theoretical input speed that could make live output disagree with the setting.
- Recursion protection from 0.4.63/0.4.64 is unchanged.

Install the same CCQ Core version on the server and clients. Existing worlds do not need to be reset.

# CCQ Core 0.4.67

相对 **0.4.64** 的累计更新，包含 0.4.65、0.4.66 与 0.4.67 的修复。

## 更新内容

- **修复万向转速控制器实际输出与设定转速不一致。** 普通传动轴、齿轮箱等接收端直接使用滚轮设定的目标转速，不再因输入理论转速为 0 而阻止目标转速传递；保留已有的输出反馈与递归保护。
- **修复多人服务器上 JEI「冷却 / 冷冻」显示互换。** 冷却条件改为按名称同步，避免客户端与服务端枚举顺序不同造成错位。
- **修复多人矿脉扫描的服务端异常。** 扫描完成、取消或玩家离线时，清理会话不再破坏正在进行的遍历。
- **修复方块喷注器的护目镜提示异常。** 查看有处理进度或配方的喷注器时，可以正常追加提示内容。
- **修复可选依赖被当作必需依赖。** 依赖声明改用 NeoForge 的 `required / optional` 类型，使相关兼容功能按实际安装情况启用。
- **修复液体雪人冷却室切换高级冷却液失败。** 罐内残留水等低级液体时，管道模拟灌入与实际灌入的接受量保持一致，高级冷却液可按设计替换低级液体。
- **修复液体雪人冷却室无效消耗低级液体。** 高级冷却仍有剩余时间时，不再提前消耗低级液体；待当前冷却耗尽后再使用。

## 升级说明

服务端与客户端请一起升级到 **0.4.67**，尤其不要与 0.4.65 混用冷却条件的网络同步格式。无需重置已有存档。

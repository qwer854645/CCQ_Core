# CCQ Core 0.4.133

相对 **ccq_core-0.4.67.jar** 的累计更新，涵盖 0.4.68—0.4.133，以本版实际保留的功能为准。

## 工程维度与传送门

- 将原独立工程试验场整合进 CCQ Core：安山岩地表、开阔平原与缓坡、丰富矿产和无洞穴地形。
- 工业铁框架使用机械动力扳手激活，采用原版传送门处理玩家与实体的传送等待、冷却和维度切换，保留 1:1 坐标与出口配对。
- 修复掉落物、经验球和静止实体传送不稳定的问题；保留 Create 原生跨维度铁路接口。
- 出口参照下界门逻辑搜索可用地表；没有天然落点时，在高度及世界边界内清理空间、铺平台并建门，水下出口增加隔水处理。

## 完整与损坏工程基地

- 新增 120×300 格的大型工程测试基地，包含宿舍、食堂、仓库、加工维修、三条炮场射击线、吊运装卸、材料场、水处理和观察值勤区域。
- 新增连锁殉爆损坏版：不规则深坑、塌落和烧蚀残骸、分散的装备守卫与保留物资；本版加入四处大型分叉紫水晶。
- 完整和损坏基地统一改为灰白混凝土外观，保留金属设备、黄色安全标线及宿舍木质生活内饰；储物集中整理，保留真实库存及随机补给。
- 补齐工作柜、切石机、灯架、雨棚和楼梯／塔架踏步的支撑，清除损坏版十个孤立残片，并修复半砖接触缝隙。
- 使用分段结构与四朝向连接状态，修复 C2ME 并行生成导致的缺段，以及 Structurify 将同一基地的相邻分段误判为重叠的问题。
- 支持 `/locate structure` 和一次 `/place structure` 放置整座基地，支持旋转、镜像、跨区块加载和损坏版地下高度偏移。

## 核弹碉堡与其他地标

- 新增双层混凝土核弹碉堡，设生活保障、加工维修、仓储、指挥区、地下核装药库和四角装甲观察室。
- 四门火炮配独立装配、回转、俯仰、反转及开火控制，开关移近炮位并排集中。水车供能，炮闩采用可升降传动架；装填和操作顺序仍需人工完成。
- 地面入口采用两层独立的 8×6 双扇装甲滑门，地下库门独立控制；重放置前回收旧门、炮位附属机构和胶水，减少旧结构残留。
- 新增蓝发女仆坐像和立像，内部各隐藏少量钻石块与下界合金块。
- 新增废弃设施：在工程维度中，以主世界出生点的 X/Z 为中心，于地表唯一生成；固定锚点和生成记录随存档保存。
- 新增野外大型紫水晶设施，随机分布于工程维度。
- 两种设施的模组储物箱、货柜、物品仓库及油罐按用途提供研究材料、维修补给、废料、电子零件、金属和少量贵重物资、燃料。生成时随机抽取，区块重载不补货。

基础候选区域边长：完整基地、损坏基地和两种女仆雕像组各为 64 区块，核弹碉堡为 80 区块，野外紫水晶设施为 32 区块。坐像与立像共用一组配额；实际密度受地形、避让及 Structurify 设置影响。废弃设施全维度唯一，不采用随机密度。

## 兼容与显示修复

- 支持官方 TACZ 1.2 分支的枪包加载前适配：默认枪包精简、应用／机动／魔艺军械旧配方转换、应用军械终端分类与组件图标修复。
- 增加枪包转换前备份、独立转换目录、串行处理和完整性检查，修复历史转换结果冲突及 Windows ZIP 占用导致旧数据继续加载的问题；旧移植版保留原处理分支。
- 修复 CBC Ballistics 1.3.0a 在设置界面反复覆盖鼠标灵敏度的问题。
- 统一英语、简体中文、俄语和雷石东语的工程维度、提示与兼容内容翻译。

## 升级说明

- 客户端与服务端一起升级。若仍装有独立 `ccq_testground`，请移除，工程维度已包含在本模组中。
- 本版基于 Minecraft 1.21.1、Java 21、NeoForge 21.1.247+，面向 Create Craft & Quiet 整合包。建筑还使用 CBC、Create Deco、Copycats、家具、电力及其他整合包模组的方块，不是只依赖原版方块的独立结构包。
- 已生成的完整／损坏基地不会自动改造；新生成或重新放置后采用新版布局。**唯一废弃设施会在首次升级时向目标区域补生成一次，包括已探索区块，放置范围内会写入建筑方块；升级前请备份存档。** 后续重启不重复重建，也不因修改主世界出生点再生成第二座。
- 不要额外安装已内嵌的 CAPG 与 BnB Cogwheel Compat 重复副本。

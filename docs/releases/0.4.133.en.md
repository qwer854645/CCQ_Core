# CCQ Core 0.4.133

Cumulative changes since **ccq_core-0.4.67.jar**, covering 0.4.68–0.4.133 and describing the features retained in this release.

## Engineering dimension and portals

- Integrate Engineering Test Ground into CCQ Core, with an andesite surface, open plains, gentle hills, rich ores and cave-free terrain.
- Activate industrial iron portal frames with a Create wrench. Use vanilla portal processing for delays, cooldowns and dimension transitions, preserving 1:1 coordinates, paired exits and Create's native interdimensional railway support.
- Fix unreliable transfers of stationary entities, dropped items and experience. Search for exits like Nether portals, with a bounded platform/frame fallback and fluid protection for submerged exits.

## Engineering bases

- Add a 120×300-block engineering base with living quarters, dining, warehouses, working machinery, three firing lanes, lifting/loading yards, material stores, waterworks and observation facilities.
- Add a chain-detonation ruin variant with deep irregular craters, collapsed structures, retained supplies and scattered equipped guards. Add four large branching amethyst formations in this release.
- Restyle both variants in gray/white concrete while retaining metal equipment, safety markings and wooden living interiors. Group storage and preserve actual inventories and random supplies.
- Support detached cabinets, cutters, light frames, awnings and stair/tower steps; close slab attachment gaps and remove ten isolated ruin fragments.
- Use sectioned structures and baked states for four rotations. Fix incomplete generation with C2ME and Structurify overlap checks between sections of the same base.
- Support locating and placing complete bases through vanilla structure commands, including rotation/mirroring, cross-chunk loading and the ruined underground offset.

## Bunker and landmarks

- Add a two-storey concrete nuclear bunker with living facilities, workshops, storage, command areas, an underground charge vault and four armored observation domes.
- Water power drives four cannons with independent assembly, yaw, pitch, reversal and firing controls, grouped beside each position. Retractable drive bridges operate the breeches; loading and operating sequences remain manual.
- Add two independently operated layers of 8×6 double-leaf armored entrance doors and a separate vault door. Recover old moving mechanisms and glue before replacement.
- Add seated and standing azure maid statues, each concealing a small number of diamond and netherite blocks.
- Add one abandoned facility centered on the overworld spawn X/Z in the engineering dimension, with a persistent fixed anchor and generation record.
- Add randomly distributed wild amethyst facilities. Both new facilities have purpose-specific native-container loot and fuel reserves, rolled during structure placement without restocking on chunk reload.

Base candidate-region widths are 64 chunks for intact bases, ruined bases and the shared statue set; 80 chunks for bunkers; and 32 chunks for wild amethyst facilities. Actual density depends on terrain, exclusions and Structurify settings. The abandoned facility is unique rather than randomly distributed.

## Compatibility and localization

- Adapt official TACZ 1.2 packs before loading: trim default content, convert legacy Applied/Mobility/Ars Armorer recipes, and repair Applied Armorer terminal categories and component icons.
- Back up packs before conversion; use independent conversion workspaces, serialized processing and completeness checks. Fix historical export conflicts and Windows ZIP file locks. Retain the legacy-port branch.
- Fix CBC Ballistics 1.3.0a repeatedly overwriting mouse sensitivity while settings screens are open.
- Unify engineering and compatibility text across English, Simplified Chinese, Russian and LeiShiDong.

## Upgrading

- Update clients and servers together. Remove a standalone `ccq_testground` JAR if present; its dimension is now included.
- Target Minecraft 1.21.1, Java 21 and NeoForge 21.1.247+. Buildings use the CCQ pack's CBC, Create Deco, Copycats, furniture, electrical and other mod blocks; they are not standalone vanilla structures.
- Existing bases are not automatically rebuilt. New generation or explicit replacement uses the new templates. **The unique abandoned facility is backfilled once on first upgrade, including in explored chunks, and writes building blocks inside its footprint. Back up the world before upgrading.** Restarts and later overworld spawn changes do not create a second facility.
- Do not install duplicate standalone copies of the embedded CAPG and BnB Cogwheel Compat modules.

## Validation for this release

Built with Java 21. The latest support repairs passed offline connectivity checks for master templates, the lodge and all four baked rotation variants. Unit tests, full regression tests and in-game tests were not rerun, as requested; historical checks do not constitute full validation of this release.
